# 📝 React To-Do List App

A responsive To-Do List built with React and CSS.

# 🚀 Features
- Add tasks
- Delete tasks
- Move tasks up and down
- Fully responsive design (mobile friendly)
- Modern CSS (clamp, flex-wrap, media queries)

# 🛠 Tech Stack
- React (useState)
- CSS3 (Flexbox + Responsive Design)

# 📱 Responsive
Works on:
- Mobile
- Tablet
- Desktop
